
## 1. 全局表：一眼看清每份文档的定位

| 文件 | 类型 | 谁看 | 回答什么问题 |
|---|---|---|---|
| `README.md` | **门面** | 所有人（第一份） | 这是什么？怎么跑起来？做成什么样了？ |
| `docs/BEGINNER_GUIDE.md` | **入门** | **完全没经验的人** | 东西在哪？从零怎么跑？每个名词什么意思？怎么讲给别人听？ |
| `docs/BUILD_NARRATIVE.md` | **过程** | 要讲解/答辩的人、接手的人 | 我是怎么一步步做出来的？踩过哪些坑？哪些决定是我自己下的？ |
| `docs/ARCHITECTURE.md` | **设计** | 要读/改代码的人、评审 | 模块边界在哪？数据怎么流？并发为什么安全？ |
| `docs/ACCEPTANCE.md` | **证据** | 评审、验收方 | 凭什么说做完了？每条要求对应哪个可复现的证据？ |
| `docs/ICD_CHANGE_REQUEST.md` | **合规** | 项目负责人、评审 | 有没有偷偷改冻结接口？ICD 没写的地方怎么处理的？ |
| `docs/tuning-log.md` | **参数** | 以后要调参的人（包括三个月后的自己） | 这些参数凭什么这么大？改了以后怎么验证没变坏？ |
| `docs/PRESENTATION.md` | **讲稿** | 要上台讲的人 | 会被问什么？每个问题怎么答？ |
| `docs/BUILD_STM32.md` | **移植** | 要在真实硬件上跑的人 | 怎么上硬件？哪些地方最容易错？ |
| `docs/data/TEST_DATA.md` | **数据**（自动生成） | 要看实测数字的人 | 实测指标具体是多少？ |
| `docs/ICD_V1.0_plaintext_extract.txt` | **原始输入** | 要核对原文的人 | 任务书原文到底怎么写的？ |
